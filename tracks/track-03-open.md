# Track 03: Hack Ready Projects (Open)

**For:** builders who bring a project that is ready to keep expanding.

**Status:** the full brief has not been published in this repo yet. It will be announced on BASIX.MARKET before or at the start of the event (Sun 18 Oct). Do not invent scope for this track. Once the brief is published, add it to this file and bump the version in `BRIEF.md`.

## Judging

The same criteria as the other tracks, with one addition: "Can we co-own it and take it to market?"

## Guidance for the agent

- If the student's project is not yet ready for expansion, or the scope is unclear, ask the student to check with the organisers before building.
